# V Sumana — Psychology Digital Portfolio

A responsive, accessible static digital portfolio created for **Managing Digital Design and Media** (B.Sc. (Hons.) Psychology, PES University, Bangalore).

## Features
- **Responsive & Accessible Design:** Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), skip-to-content navigation, keyboard-accessible interactive components, and automatic light/dark mode support.
- **Interactive Psychology Content:**
  - **Stress Response Infographic:** 4-stage visual breakdown of the physiological stress response.
  - **Myth vs. Fact Flip Cards:** Interactive cards addressing common mental health misconceptions.
  - **4-4-4-4 Box Breathing Simulator:** Animated slow-breathing exercise with `aria-live` screen reader announcements and `prefers-reduced-motion` support.
- **Zero External Dependencies:** All styles, scripts, and embedded assets are self-contained inside `index.html` for fast, reliable static hosting.

## Deploying to GitHub Pages
1. Create a new public repository on GitHub (for example, `vsumana.github.io` or `psychology-portfolio`).
2. Upload the contents of this folder (`index.html`, `README.md`, and `.nojekyll`) to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your site will be live within 1–2 minutes at `https://<your-username>.github.io/<repository-name>/`.
